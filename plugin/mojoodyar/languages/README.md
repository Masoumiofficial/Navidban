# پوشهٔ زبان

موجودیار برای فروشگاه‌های فارسی‌زبان نوشته شده است: تمام متن رابط کاربری و
پنل مدیریت **مستقیماً فارسی** است، نه از راه فایل ترجمه. دلیلش ساده است —
ترجمهٔ ماشینی متن‌های حقوقی (رضایت، حریم خصوصی) در فروشگاه ایرانی ریسک
کمتر و دلیل کمتری برای اشتباه دارد.

بنابراین `mojoodyar.pot` فقط شامل رشته‌هایی است که واقعاً از تابع ترجمهٔ
وردپرس عبور می‌کنند (در حال حاضر: برچسب بازهٔ cron). این قالب برای الزام
ابزارهای بسته‌بندی وردپرس و برای امکان ترجمهٔ همین چند رشته نگه داشته شده
است.

اگر می‌خواهید رابط را به زبان دیگری ترجمه کنید، فایل
`mojoodyar-{locale}.po` را در همین پوشه بگذارید؛ وردپرس آن را در
`load_plugin_textdomain()` پیدا می‌کند. توجه: متن‌های ثابت فارسی که از
تابع ترجمه عبور نمی‌کنند با این روش ترجمه **نمی‌شوند** — این محدودیت
مستند است، نه باگ پنهان.
