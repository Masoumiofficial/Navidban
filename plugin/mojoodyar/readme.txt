فرم «خبرم کن» روی محصول ناموجود، با تأیید دومرحله‌ای، صف ارسال پس‌زمینه و
پیامک ایرانی. صفر بایت روی بقیهٔ صفحات سایت.

== Description ==

موجودیار وقتی کالایی تمام می‌شود، مشتری را از دست نمی‌دهد: مشتری شماره یا
ایمیل می‌گذارد، به‌محض بازگشت موجودی خبر می‌گیرد.

**آنچه این افزونه را متفاوت می‌کند**

* **صفر بارگذاری اضافه.** استایل و اسکریپت فقط در صفحهٔ محصولی که ناموجود
  است (یا تنوعی ناموجود دارد) بارگذاری می‌شود. روی خانه، آرشیو، دسته،
  جست‌وجو، سبد و تسویه حساب: صفر درخواست، صفر بایت. این عدد اندازه‌گیری شده
  است، نه ادعا: `docs/PERFORMANCE.md`.
* **PHP 7.4 تا 8.3.** بدون Composer، بدون npm، بدون build، بدون IonCube،
  بدون کلید لایسنس، بدون تماس با سرور ما.
* **اعلام به تعداد موجودی.** ۵ واحد برگشت = ۵ اعلان، به قدیمی‌ترین منتظران.
* **تشخیص موجودی دولایه.** هوک‌های ووکامرس برای تغییرهای معمول، و پایش
  تطبیقی برای وقتی موجودی با CSV/ERP/SQL مستقیم عوض می‌شود.
* **تأیید دومرحله‌ای** تا کسی به‌جای دیگری ثبت‌نام نکند، و **پیوند لغو** در
  هر پیام.
* **پنل فارسی راست‌چین** با تاریخ شمسی، ارقام فارسی، فیلتر و خروجی CSV.

**کانال‌ها:** ایمیل (wp_mail) · ملی‌پیامک · آی‌پی‌پنل · کاوه‌نگار · درگاه
عمومی REST با محافظت SSRF.

== Installation ==

1. zip را در **افزونه‌ها → افزودن → بارگذاری** نصب و فعال کنید.
2. یک محصول را ناموجود کنید و صفحه‌اش را باز کنید.
3. در **موجودیار → ابزارها** یک ایمیل آزمایشی بفرستید.

== Frequently Asked Questions ==

= آیا بدون ووکامرس کار می‌کند؟ =
نه. برای فرم روی صفحهٔ محصول و تشخیص موجودی، ووکامرس لازم است.

= آیا داده‌ای به سرور شما می‌فرستد؟ =
نه. تنها تماس خروجی، به درگاه پیامکی است که خودتان تنظیم می‌کنید.

= با حذف افزونه داده‌ها پاک می‌شوند؟ =
نه، مگر گزینهٔ «حذف داده هنگام حذف افزونه» را روشن کرده باشید.

= می‌توانم فقط پیامک داشته باشم؟ =
بله. تنظیمات → کانال‌ها → پیامک را روشن کنید و حالت انتخاب را روی «پیامک» بگذارید.

= روی چه نسخه‌ای تست شده است؟ =
اجرا روی PHP 8.3.33 و 7.4.33 با هارنس تست. نصب واقعی WordPress/WooCommerce
در محیط توسعه در دسترس نبود؛ جزئیات صادقانه در `docs/TEST-REPORT.md`.

== Compatibility ==

این جدول عمداً «تست‌شده» و «آزمون‌نشده» را از هم جدا می‌کند. جای تیک سبز،
واقعیت نوشته شده است.

| محیط | وضعیت |
|---|---|
| PHP 7.4.33 | تست‌شده (۴۱۱ + ۴۶۰ + ۱۷۹ بررسی، ۰ خطا) |
| PHP 8.3.33 | تست‌شده (همان مجموعه) |
| PHP 8.0 تا 8.2 | همان codebase؛ آزمون جداگانه اجرا نشده |
| PHP 8.4 | داده در دسترس نیست |
| وردپرس ۶.۴ و بالاتر | حداقل اعلام‌شده؛ آزمون روی نصب واقعی وردپرس انجام نشده |
| ووکامرس ۹.۰ و بالاتر | حداقل اعلام‌شده؛ آزمون روی نصب واقعی ووکامرس انجام نشده |
| HPOS (جدول سفارش‌ها) | سازگاری در کد اعلام شده؛ روی نصب واقعی تست نشده |
| وردپرس چندسایتی | کد به `wp_posts` وابسته نیست؛ تست نشده |
| WPML / چندزبانه | داده در دسترس نیست |
| ترجمهٔ رابط کاربری | رابط کاربری فارسی است و لایهٔ ترجمه ندارد؛ خارج از دامنهٔ این نسخه |

«تست‌شده» یعنی آزمون خودکار روی همان نسخه اجرا و نتیجه‌اش ذخیره شده است
(`docs/TEST-REPORT.md`). یعنی روی یک نصب واقعی ووکامرس نصب و آزمایش نشده —
این کار را قبل از فروش انجام می‌دهیم و همین جدول را به‌روز می‌کنیم.

== Changelog ==

= 1.0.0 =
اولین انتشار عمومی. همهٔ موارد زیر در همین نسخه هست و آزمون‌شده است:

* فرم «خبرم کن» فقط روی صفحهٔ محصول ناموجود (و هر تنوع ناموجود) بارگذاری می‌شود؛ صفر فایل و صفر کوئری روی بقیهٔ صفحات.
* دو کانال: پیامک (ملی‌پیامک با الگو/bodyId، کاوه‌نگار، آی‌پی‌پنل، درگاه REST عمومی) و ایمیل با پوستهٔ اختصاصی.
* صف پس‌زمینه با قفل ردیف، بازپس‌گیری ردیف رهاشده، عقب‌نشینی ۱۵ دقیقه/۱ ساعت/۶ ساعت، سقف تلاش قابل تنظیم و نرخ ارسال در دقیقه.
* ارسال منصفانه: به تعداد واحدهای برگشته پیام می‌رود، نه به همهٔ منتظران؛ قدیمی‌ترین درخواست اول.
* تشخیص موجودی دولایه: قلاب‌های ووکامرس + پایش تطبیقی هر ۱۵ دقیقه (اجرای اول فقط عکس‌برداری می‌کند).
* پنل فارسی راست‌به‌چپ: داشبورد، لیست انتظار، آمار، پیگیری تلفنی مرحله‌ای، تنظیمات، ابزارها، راهنما و گزارش رویدادها با توضیح فارسی و لاگ خام.
* تأیید دو مرحله‌ای اختیاری، خروجی CSV با BOM، تاریخ شمسی، ارقام فارسی.
* بدون Composer، بدون npm، بدون build، بدون IonCube، بدون لایسنس‌سرور و بدون هیچ تماس با سرور سازنده.
