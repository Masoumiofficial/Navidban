فرم «خبرم کن» روی محصول ناموجود، با تأیید دومرحله‌ای، صف ارسال پس‌زمینه و
پیامک ایرانی. صفر بایت روی بقیهٔ صفحات سایت.

== Description ==

نویدبان وقتی کالایی تمام می‌شود، مشتری را از دست نمی‌دهد: مشتری شماره یا
ایمیل می‌گذارد، به‌محض بازگشت موجودی خبر می‌گیرد.

**آنچه این افزونه را متفاوت می‌کند**

* **صفر بارگذاری اضافه.** استایل و اسکریپت فقط در صفحهٔ محصولی که ناموجود
  است (یا تنوعی ناموجود دارد) بارگذاری می‌شود. روی خانه، آرشیو، دسته،
  جست‌وجو، سبد و تسویه حساب: صفر درخواست، صفر بایت. این عدد اندازه‌گیری شده
  است، نه ادعا: `docs/PERFORMANCE.md`.
* **PHP 7.4 تا 8.3.** بدون Composer، بدون npm، بدون build، بدون IonCube،
  بدون کلید لایسنس، بدون تماس با سرور ما.
* **اعلام به تعداد موجودی.** ۵ واحد برگشت = ۵ اعلان، به قدیمی‌ترین منتظران.
* **تشخیص موجودی دولایه.** هوک‌های ووکامرس برای تغییرهای معمول، و پایش
  تطبیقی برای وقتی موجودی با CSV/ERP/SQL مستقیم عوض می‌شود.
* **تأیید دومرحله‌ای** تا کسی به‌جای دیگری ثبت‌نام نکند، و **پیوند لغو** در
  هر پیام.
* **پنل فارسی راست‌چین** با تاریخ شمسی، ارقام فارسی، فیلتر و خروجی CSV.

**کانال‌ها:** ایمیل (wp_mail) · ملی‌پیامک · آی‌پی‌پنل · کاوه‌نگار · درگاه
عمومی REST با محافظت SSRF.

== Installation ==

1. zip را در **افزونه‌ها → افزودن → بارگذاری** نصب و فعال کنید.
2. یک محصول را ناموجود کنید و صفحه‌اش را باز کنید.
3. در **نویدبان → ابزارها** یک ایمیل آزمایشی بفرستید.

== Frequently Asked Questions ==

= آیا بدون ووکامرس کار می‌کند؟ =
نه. برای فرم روی صفحهٔ محصول و تشخیص موجودی، ووکامرس لازم است.

= آیا داده‌ای به سرور شما می‌فرستد؟ =
نه. تنها تماس خروجی، به درگاه پیامکی است که خودتان تنظیم می‌کنید.

= با حذف افزونه داده‌ها پاک می‌شوند؟ =
نه، مگر گزینهٔ «حذف داده هنگام حذف افزونه» را روشن کرده باشید.

= می‌توانم فقط پیامک داشته باشم؟ =
بله. تنظیمات → کانال‌ها → پیامک را روشن کنید و حالت انتخاب را روی «پیامک» بگذارید.

= روی چه نسخه‌ای تست شده است؟ =
اجرا روی PHP 8.3.33 و 7.4.33 با هارنس تست. نصب واقعی WordPress/WooCommerce
در محیط توسعه در دسترس نبود؛ جزئیات صادقانه در `docs/TEST-REPORT.md`.
