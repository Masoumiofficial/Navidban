## ۳) دستی — روی نصب واقعی (انجام‌نشده)

این‌ها باید پیش از انتشار عمومی روی یک نصب واقعی اجرا شوند:

- [ ] نصب zip روی WordPress 6.9 + WooCommerce 10.x با PHP 8.3.
- [ ] ساخت محصول ساده با موجودی ۰ → فرم دیده شود.
- [ ] ثبت ایمیل → دریافت پیام تأیید → کلیک → وضعیت `confirmed`.
- [ ] افزایش موجودی به ۵ از پیشخوان ووکامرس → ۵ اعلان در صف.
- [ ] تغییر موجودی با `UPDATE wp_postmeta` مستقیم → پایش تطبیقی بگیرد.
- [ ] تغییر موجودی به ۸ (۵+۳) → فقط ۳ اعلان تازه.
- [ ] لغو اشتراک از پیوند داخل پیام → ردیف `unsubscribed`.
- [ ] خروجی CSV در اکسل با BOM درست باز شود.
- [ ] حذف افزونه بدون گزینهٔ حذف داده → جدول‌ها بمانند.
- [ ] حذف با گزینهٔ روشن → چهار جدول و همهٔ آپشن‌ها پاک شوند.
- [ ] HPOS روشن → ارسال اعلان کار کند.
- [ ] network-activate روی شبکهٔ دو سایتی.
- [ ] WP-Cron واقعی (cron سیستم) → صف بدون بازدید ترافیک تخلیه شود.
- [ ] یک درگاه پیامک واقعی (ملی‌پیامک یا کاوه‌نگار) با اعتبار واقعی.
- [ ] ثبت از فرم با نام → نام در ستون «مشتری»، در پیامک (`{0}`) و در CSV دیده شود.
- [ ] ثبت بدون نام با کلید «نام اجباری» روشن → خطای ۴۲۲ و ردیف ساخته نشود.
- [ ] تیک «تماس گرفته شد» روی یک ردیف → تاریخ شمسی کنارش بیاید و با فیلتر
