# فهرست تصاویر صفحهٔ فروش (۹ تصویر)

> پروندهٔ توسعه — در بستهٔ انتشار نمی‌آید.
> **وضعیت واقعی: هیچ‌کدام از این تصاویر گرفته نشده است.** در این محیط
> مرورگر و WordPress نصب نیست؛ ساختن تصویر جعلی از رابط کاربری، تخلف
> صادقانه است. این‌ها «فهرست نماها + دستورالعمل گرفتن» هستند.

قاعدهٔ ثبت: عرض ۱۴۴۰ پیکسل، بزرگ‌نمایی صفحه ۱۰۰٪، پنهان‌کردن نوار مدیریت
فقط در تصاویر فرانت، دادهٔ نمونهٔ فارسی واقع‌نما (نه لورم ایپسوم)، بدون
اطلاعات شخصی واقعی.

## روش گرفتن

1. روی نصب آزمایشی با محصول ناموجود و ۲۰ ردیف دادهٔ نمونه.
2. `wp option update navidban_settings --format=json` را قبلش برای دادهٔ
   نمونه اجرا کنید (یا از ابزارها استفاده کنید).
3. DevTools → Device toolbar → عرض ۱۴۴۰.
4. `Ctrl+Shift+P` → «Capture screenshot» (تمام صفحه) یا
   «Capture node screenshot» (نود خاص).
5. فایل‌ها: `screenshot-1.png` … `screenshot-9.png`، حداکثر ۱ مگابایت هر کدام.

## چیزهایی که در تصاویر نباید باشد

- ایمیل/موبایل واقعی مشتری.
- کلید درگاه پیامک (حتی پوشیده، اگر قابل خواندن است).
- نام رقبا در تب مرورگر یا بوکمارک‌بار.
